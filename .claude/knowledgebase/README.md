# Axis And Allies Project — Knowledgebase

Detailed reference material. **Loaded on demand, not every session** — keep the
always-loaded context in `../../CLAUDE.md` instead.

## Structure

```
knowledgebase/
├── game-design/       # Rules, mechanics, balance intent
├── map-architecture/  # Territory/adjacency design, Civ V research
├── algorithms/        # Map generation, pathfinding, combat odds
├── previous-work/     # Notes from past sessions worth keeping
└── reference/         # Rulebook extracts, inspiration, external sources
```

Folders are created as material arrives — don't pre-create empty ones.

## Already in the project root

Two substantial reference documents live at the project root rather than here,
because they predate this structure:

- `civ5_map_architecture_deep_dive.md` — map architecture research
- `A&A_40Anni_Rulebook_WEB.pdf` — official rulebook (7.9 MB)

Link to them; don't duplicate them into this folder.

## What belongs here

- Balance rationale — why a unit costs what it costs
- Map generation and pathfinding algorithm notes
- Extracts from the rulebook that a decision actually turned on
- Prior session notes that future work depends on

## What does not

- Requirements → `../REQUIREMENTS.md`
- Decisions → `../DECISIONS.md`
- Open questions → `../OPEN_QUESTIONS.md`
- Large binaries — reference them by path

## Naming

Date-prefix anything time-bound: `2026-08-12-combat-odds-notes.md`.
